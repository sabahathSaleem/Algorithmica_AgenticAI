🧠 PART 1 — Key Concepts Used in This File

📂 pathlib.Path — Smart File Paths

Path is Python's modern way to handle file and folder locations. Instead of messy string joining like "folder" + "/" + "file.pdf", you just write Path("folder") / "file.pdf". It works on Windows, Mac, and Linux automatically!

🗂️ Real life: Think of Path as Google Maps for your computer's files. You tell it where you want to go, and it figures out the correct route whether you're on Windows or Mac.

🖼️ pdf2image — PDFs Are Just Pictures!

AI Vision models (like Claude) read images, not raw PDF binary data. So we convert each PDF page into a JPG image first. pdf2image uses a tool called Poppler under the hood to do this conversion.

📸 Real life: It's like taking a photo of a paper document before scanning it into your phone. The AI needs to "see" the invoice just like you see it — as an image.

🗂️ tempfile — The Scratch Paper Trick

tempfile.TemporaryDirectory() creates a folder that automatically deletes itself when you're done. We use it to store intermediate image files during PDF conversion — no need to clean up manually!

🧻 Real life: Like using a whiteboard at school to do rough work — when class ends, the board is wiped clean. You never have to "clean up" after yourself!

📊 Pandas — The Spreadsheet Wizard

Pandas is Python's most popular data library. A DataFrame is basically an Excel table in Python — rows and columns of data you can filter, group, sort, and calculate on. This file uses pandas to stack all invoices into one big table and crunch the numbers.

📋 Real life: Imagine you collected 100 paper invoices and typed them all into one Excel sheet. Pandas does that automatically — and also does all the SUM, GROUP BY, and AVERAGE calculations for you!

🔍 Flattening Nested Data

Our Invoice object is nested — it has a Company inside it which has its own fields. A Pandas DataFrame needs a flat table (no nesting). So we "flatten" it — pulling all nested values up to the top level with descriptive keys like "Issuer Name", "Recipient Email".

📦 Real life: Imagine a Russian doll (Matryoshka). You can't put it in a flat envelope without taking all the dolls apart and laying them side by side. Flattening = opening all the dolls!

📈 xlsxwriter — Drawing in Excel with Code

xlsxwriter lets Python write Excel files (.xlsx) with full formatting — bold text, custom number formats, charts, multiple sheets. It's like having a robot that fills in Excel for you perfectly every time.

🤖 Real life: Normally you'd open Excel, type data, add formatting, create a chart — manually. xlsxwriter does ALL of that in seconds, for 1000 invoices!

🔗 zip() — Pairing Two Lists Together

zip(list_a, list_b) pairs items from two lists together, one by one. Here we zip filenames with invoice objects — so we always know which filename belongs to which invoice when something goes wrong.

👟 Real life: Like matching left shoes to right shoes. zip() makes sure shoe #1 always pairs with its partner, shoe #2 with its partner, etc.

Function 1 — list_all_files()
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 🔍 FUNCTION 1: list_all_files
# Job: Scan a folder and return all files with a given extension
# Why: Before processing, we need to FIND all invoice PDFs
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

def list_all_files(directory: Path, extension: str = "pdf") -> list[Path]:
    # directory: the folder to scan (e.g. Path("/invoices"))
    # extension: what file type to look for (default = "pdf")
    # -> list[Path]: returns a list of full file paths

    return [
        Path(directory, f)           # Build a full path: /invoices/bill_jan.pdf
        for f in os.listdir(directory) # Loop through every file in the folder
        if f.lower().endswith(extension) # Only keep files ending in "pdf" (case-insensitive)
        # .lower() → converts "INVOICE.PDF" to "invoice.pdf" so the check always works
    ]
    # This is a LIST COMPREHENSION — a compact Python loop that builds a list in one line
    # Equivalent to: results = []; for f in ...: if ...: results.append(Path(directory, f))
Function 2 — pdf_to_jpg()
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 🖼️  FUNCTION 2: pdf_to_jpg
# Job: Convert every PAGE of a PDF into a separate JPG image
# Why: AI Vision models need IMAGE input, not raw PDF bytes!
#      A 3-page PDF → [page_0.jpg, page_1.jpg, page_2.jpg]
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

def pdf_to_jpg(file_path: Path, save_dir: Path) -> list[Path]:

    save_dir.mkdir(parents=True, exist_ok=True)
    # mkdir → create the output folder if it doesn't exist
    # parents=True  → also create any missing parent folders (/a/b/c all at once)
    # exist_ok=True → don't crash if folder already exists

    filename = Path(file_path).stem
    # .stem → gets filename WITHOUT extension
    # Path("invoices/bill_jan.pdf").stem → "bill_jan"
    # Used to name the output JPGs: "bill_jan_page_0.jpg", etc.

    image_paths = []   # We'll collect all the saved JPG paths here

    with tempfile.TemporaryDirectory() as path:
        # Creates a temporary scratch folder — automatically deleted when 'with' block ends
        # This is where pdf2image dumps its intermediate files before we save the final JPG

        images = convert_from_path(file_path, output_folder=path)
        # 📖 Reads the PDF and returns a list of PIL Image objects (one per page)
        # PIL = Python Imaging Library — an image object you can resize, crop, save, etc.
        # output_folder=path → pdf2image uses our temp dir for scratch work

        for idx, image in enumerate(images):
            # enumerate() gives us both the index (0,1,2...) and the image object
            # So idx=0 → first page, idx=1 → second page, etc.

            save_path = Path(save_dir, f"{filename}_page_{idx}.jpg")
            # Build final save path e.g. "output/bill_jan_page_0.jpg"

            image.save(save_path, "JPEG")
            # Save the PIL Image as a JPEG file to disk

            image_paths.append(save_path)
            # Remember this path so we can return all of them

    return image_paths
    # The temp directory is now GONE (auto-deleted)
    # But our saved JPGs in save_dir are permanent — perfect!
Function 3 — flatten_invoice_structure()
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 🔓 FUNCTION 3: flatten_invoice_structure
# Job: Convert a NESTED Invoice object → a FLAT dictionary
#
# PROBLEM: Invoice has Company inside it, which has name/phone/email...
# Pandas DataFrames need flat rows — no nesting allowed!
#
# NESTED (bad for pandas):         FLAT (good for pandas):
# invoice.issuer.name = "ACME"  →  "Issuer Name": "ACME"
# invoice.issuer.phone = "..."  →  "Issuer Phone": "..."
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

def flatten_invoice_structure(invoice):
    # invoice: an Invoice Pydantic object (from invoice.py)

    flat = {
        # ── Top-level invoice fields ──────────────────────
        'Invoice Number': invoice.invoice_number,    # e.g. "INV-2025-001"
        'Invoice Date':   invoice.invoice_date,      # date object
        'Invoice Type':   invoice.invoice_type,      # "incoming" / "outgoing" / None

        # ── Issuer (the sender company) ────────────────────
        'Issuer Name':    invoice.issuer.name,        # Dot-chaining: invoice → issuer → name
        'Issuer Address': invoice.issuer.address,
        'Issuer Phone':   invoice.issuer.phone,
        'Issuer Email':   invoice.issuer.email,

        # ── Recipient (the receiver company) ──────────────
        'Recipient Name':    invoice.recipient.name,
        'Recipient Address': invoice.recipient.address,
        'Recipient Phone':   invoice.recipient.phone,
        'Recipient Email':   invoice.recipient.email,

        # ── Financial totals ──────────────────────────────
        'Subtotal':  invoice.subtotal,
        'Tax Rate':  invoice.tax_rate,
        'Tax':       invoice.tax,
        'Total':     invoice.total,
        'Terms':     invoice.terms,
    }

    for i, item in enumerate(invoice.invoice_items, 1):
        # enumerate(..., 1) → starts counting from 1 (not 0) → "Item 1", "Item 2", ...
        flat[f'Item {i} Description'] = item.description
        flat[f'Item {i} Total']       = item.total
        # Dynamic keys! If there are 3 items, this creates:
        # "Item 1 Description", "Item 1 Total"
        # "Item 2 Description", "Item 2 Total"
        # "Item 3 Description", "Item 3 Total"
        # ⚠️ SIDE EFFECT: If invoices have different numbers of items,
        # some rows will have NaN (empty) for missing item columns in the DataFrame

    return flat  # A plain Python dictionary — ready for Pandas!
Function 4 — build_invoices_dataframe()
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 📊 FUNCTION 4: build_invoices_dataframe
# Job: Take ALL invoice objects → build ONE big Pandas table
# Also adds a "Year-Month" column so we can group by month later
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

def build_invoices_dataframe(invoices_filenames, invoices):
    # invoices_filenames: list of filenames ["jan.pdf", "feb.pdf", ...]
    # invoices: list of Invoice objects (one per file)

    flat_invoices = []  # Will become a list of dicts → one dict per invoice

    for filename, invoice in zip(invoices_filenames, invoices):
        # zip() pairs each filename with its matching invoice object
        # So we always know: THIS invoice came from THAT file

        try:
            flat_invoice = flatten_invoice_structure(invoice)
            # Call our Function 3 to flatten the nested Invoice → dict
            flat_invoices.append(flat_invoice)

        except Exception as e:
            print(f'Unexpected error in invoice {filename}: {e}')
            # If ONE invoice is broken, we skip it and continue — not crash everything!
            # This is called DEFENSIVE PROGRAMMING — always expect surprises in real data

    invoices_df = pd.DataFrame(flat_invoices)
    # pd.DataFrame(list_of_dicts) → stacks all dicts into a table
    # Each dict = one ROW; dict keys become COLUMN NAMES

    invoices_df['Invoice Date'] = pd.to_datetime(invoices_df['Invoice Date'])
    # Convert date objects to Pandas Timestamp — enables time-based operations
    # e.g. .dt.year, .dt.month, date comparisons, resampling, etc.

    invoices_df.insert(2, 'Year-Month', invoices_df['Invoice Date'].dt.to_period('M'))
    # insert(2, ...) → add a new column at position 2 (3rd column)
    # .dt.to_period('M') → converts "2025-06-15" to Period("2025-06") — month label
    # This lets us GROUP invoices by month later: all June invoices together, etc.

    return invoices_df
Function 5 — generate_financial_summary()
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 🧮 FUNCTION 5: generate_financial_summary
# Job: Crunch numbers — overall totals AND month-by-month breakdown
# Returns TWO things: (total_s, monthly_df)
#   total_s   = a pd.Series — one overall summary (like a key-value list)
#   monthly_df = a DataFrame — one row per month
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

def generate_financial_summary(invoices_df):

    total_s = pd.Series(dtype='object')
    # pd.Series = a single column of labelled values (like a Python dict but pandas-powered)
    # dtype='object' → allows mixed types (strings + numbers)

    # ── Period label ──────────────────────────────────────────────────
    total_s['Period'] = (
        f"{invoices_df['Invoice Date'].min().strftime('%Y-%m')} to "
        f"{invoices_df['Invoice Date'].max().strftime('%Y-%m')}"
    )
    # .min() and .max() → find earliest and latest invoice dates
    # .strftime('%Y-%m') → format as "2025-01" (year-month text)

    total_s['Invoices'] = len(invoices_df)  # Total count of all invoices

    # ── Revenue (outgoing invoices = money we earn) ────────────────────
    revenue = invoices_df[invoices_df['Invoice Type'] == 'outgoing']['Total'].sum()
    # invoices_df[condition] → FILTER rows where Invoice Type is "outgoing"
    # ['Total'] → pick just the Total column from those filtered rows
    # .sum() → add them all up → that's our revenue!

    expenses = invoices_df[invoices_df['Invoice Type'] == 'incoming']['Total'].sum()
    # Same pattern but for "incoming" invoices = money we spent = expenses

    total_s['Revenue']   = revenue
    total_s['Expenses']  = expenses
    total_s['Net Income'] = revenue - expenses  # Profit = what's left after expenses

    # ── Tax calculations ───────────────────────────────────────────────
    total_tax_collected = invoices_df[invoices_df['Invoice Type'] == 'outgoing']['Tax'].sum()
    total_tax_paid      = invoices_df[invoices_df['Invoice Type'] == 'incoming']['Tax'].sum()
    total_s['Tax Collected'] = total_tax_collected
    total_s['Tax Paid']     = total_tax_paid
    total_s['Net Tax']      = total_tax_collected - total_tax_paid
    # Net Tax = Tax we charged clients MINUS tax we paid suppliers
    # This is how GST/VAT accounting works — you only pay the DIFFERENCE to the government

    # ── Monthly breakdown ──────────────────────────────────────────────
    monthly_df = invoices_df.groupby('Year-Month').agg(**{
        # .groupby('Year-Month') → group all rows that share the same month
        # .agg(**{...}) → for each group, apply these aggregation functions

        'Invoices':      ('Invoice Number', 'count'),
        # Count how many invoices in each month

        'Revenue':       ('Total', lambda x: x[invoices_df['Invoice Type'] == 'outgoing'].sum()),
        # lambda = a tiny anonymous function: filter to 'outgoing' rows, then sum their Total

        'Expenses':      ('Total', lambda x: x[invoices_df['Invoice Type'] == 'incoming'].sum()),
        'Tax Collected': ('Tax',   lambda x: x[invoices_df['Invoice Type'] == 'outgoing'].sum()),
        'Tax Paid':      ('Tax',   lambda x: x[invoices_df['Invoice Type'] == 'incoming'].sum()),
    })

    monthly_df = monthly_df.reset_index()
    # reset_index() → moves 'Year-Month' from being the row INDEX back to a regular column

    monthly_df['Year-Month'] = monthly_df['Year-Month'].astype(str)
    # Convert Period objects ("2025-06") to plain strings — needed for Excel export

    monthly_df.insert(4, 'Net Income', monthly_df['Revenue'] - monthly_df['Expenses'])
    monthly_df['Net Tax'] = monthly_df['Tax Collected'] - monthly_df['Tax Paid']

    return total_s, monthly_df.T
    # .T = TRANSPOSE — flips rows and columns (months become columns, metrics become rows)
    # This makes it look nicer in the Excel Summary sheet layout
Function 6 — create_excel_report()
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 📈 FUNCTION 6: create_excel_report
# Job: Write everything to a REAL .xlsx Excel file with:
#      - Sheet 1 "Invoices" → all invoice data
#      - Sheet 2 "Summary"  → totals + monthly + a line chart
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

def create_excel_report(invoices_df, total_s, monthly_df, filepath):

    with pd.ExcelWriter(filepath, engine='xlsxwriter', datetime_format='YYYY-MM-DD') as writer:
        # ExcelWriter → Pandas wrapper that manages writing to Excel
        # engine='xlsxwriter' → use xlsxwriter library for advanced formatting
        # datetime_format → how dates appear in Excel cells
        # 'with' block → file is saved & closed automatically when done

        # ── SHEET 1: Raw invoice data ──────────────────────
        invoices_df.to_excel(writer, sheet_name='Invoices', index=False)
        # Dumps the entire DataFrame as a sheet called "Invoices"
        # index=False → don't write the row numbers (0,1,2...) as a column

        # ── SHEET 2: Summary (built manually for full control) ──
        workbook  = writer.book       # The xlsxwriter Workbook object
        worksheet = workbook.add_worksheet('Summary')  # Create a blank new sheet

        # ── Define cell formats ────────────────────────────
        title_format = workbook.add_format({'bold': True, 'font_size': 14})
        # Makes text BOLD and size 14 — for section headers like "TOTAL" and "MONTHLY"

        money_format = workbook.add_format({'num_format': '#,##0.00'})
        # Formats numbers as currency: 1234567.8 → "1,234,567.80"
        # #,##0.00 → commas every 3 digits, always 2 decimal places

        # ── Write TOTAL summary section ────────────────────
        worksheet.write('A1', 'TOTAL', title_format)
        # Write the word "TOTAL" to cell A1 with bold/large formatting

        total_s.to_frame().to_excel(writer, sheet_name='Summary', startrow=1, startcol=0, header=False)
        # .to_frame() → converts the Series into a 2-column DataFrame (labels | values)
        # startrow=1 → start at row 2 (below the "TOTAL" header)
        # header=False → don't repeat column headers

        # ── Write MONTHLY section ──────────────────────────
        worksheet.write('A12', 'MONTHLY', title_format)
        monthly_df.to_excel(writer, sheet_name='Summary', startrow=12, startcol=0, header=False)
        # Placed further down the same sheet (row 12) — below the totals section

        # ── Apply money format to specific rows ────────────
        money_rows = list(range(3, 9)) + list(range(14, 20))
        for row in money_rows:
            worksheet.set_row(row, None, money_format)
        # set_row(row_num, height, format) → applies money_format to entire rows
        # These are the rows containing Revenue, Expenses, Net Income, Tax figures

        # ── Create a LINE CHART ────────────────────────────
        chart = workbook.add_chart({'type': 'line'})
        # Creates an empty line chart object — we'll add data series to it next

        num_cols = monthly_df.shape[1]
        # .shape → (rows, columns) of the DataFrame
        # .shape[1] → just the column count = number of months
        # We need this to tell the chart "data goes from column 1 to column N"

        for i, metric in enumerate(['Revenue', 'Expenses', 'Net Income']):
            chart.add_series({
                'name':       metric,
                'categories': ['Summary', 12, 1, 12, num_cols],
                # X-axis: row 12 (the month labels row), columns 1 to num_cols
                'values':     ['Summary', 14 + i, 1, 14 + i, num_cols],
                # Y-axis: Revenue is at row 14, Expenses at 15, Net Income at 16 (14+0, 14+1, 14+2)
            })

        chart.set_x_axis({'name': 'Month'})
        chart.set_y_axis({'name': 'Amount', 'major_gridlines': {'visible': False}})
        # Label the axes; remove horizontal gridlines for a cleaner look

        worksheet.insert_chart('A23', chart)
        # Place the finished chart starting at cell A23 (below the monthly data)
