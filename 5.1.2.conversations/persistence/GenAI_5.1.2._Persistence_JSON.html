🧠 The Problem: AI Memory Dies When You Close the Program!

Remember from the last lesson — stateful agents pass message_history to remember things. But that history only lives in your computer's RAM (temporary memory). When you close your Python script... POOF! 💨 Gone forever.

These two files solve that! json_serialize.py saves the conversation to a .json file on your hard drive (permanent). json_deserialize.py loads it back later so the AI can continue EXACTLY where it left off — even days later!

🏫 Key Concepts to Know First
🔄

Serialize = Save to JSON

Serialization = turning a complex Python object (like a list of AI messages) into a simple text format (JSON) that can be written to a file. Like flattening a 3D sculpture into a 2D blueprint so you can store it!

📥

Deserialize = Load from JSON

Deserialization = the reverse! Taking that flat JSON text and rebuilding it back into the proper Python objects the AI understands. Like using the blueprint to reconstruct the 3D sculpture!

🧬

ModelMessagesTypeAdapter

A special pydantic_ai tool that knows the exact "shape" of AI messages. It can serialize (dump_json) and deserialize (validate_python) message history correctly — without losing any detail!

📂

pathlib.Path

A smart Python way to work with file paths. Instead of messy string joins like "../data/file.json", Path objects work on Windows, Mac AND Linux automatically. __file__ = this script's location.

📝

JSON Format

JSON (JavaScript Object Notation) = a text format that looks like Python dicts/lists. It's the universal language of the web. AI message history gets saved as a big JSON array of message objects.

✂️

Summarization Pattern

Before saving, the code asks the AI to summarize the whole conversation. This is a classic AI technique — instead of saving 100 messages, save 1 summary + history. Keeps the memory compact!

📸

📸 Think of it Like a Photo vs a Polaroid!

The AI's chat history in RAM is like a live scene in front of you — beautiful but temporary. json_serialize.py takes a Polaroid photo (saves to JSON file). json_deserialize.py looks at the photo (loads JSON) and recreates the scene so the AI can continue from the same point!

💚 File 1 — json_serialize.py (The SAVER)
💾 json_serialize.py STEP 1 — CHAT & SAVE
🎯 What this file does: Runs an interactive chat loop where you type messages and the AI replies. When you type q to quit, it asks the AI to summarize the whole conversation, then saves everything to a history.json file so it can be loaded later!
⭐ 3 superpowers in one file: (1) Live chat loop with memory, (2) Auto-summarization before saving, (3) Persistent JSON storage with ModelMessagesTypeAdapter.dump_json() 
# ── IMPORTS ────────────────────────────────────────────────────────────
from pathlib import Path              # 📂 Smart cross-platform file path handling
from dotenv import load_dotenv         # 🔑 Load secrets from .env file
from pydantic_ai import Agent, ModelMessagesTypeAdapter
#                               ☝️ ModelMessagesTypeAdapter = the JSON translator for AI messages
import logfire                          # 🪵 AI monitoring / CCTV tool

load_dotenv(override=True)
logfire.configure()
logfire.instrument_pydantic_ai()

# ── CREATE THE AI AGENT ────────────────────────────────────────────────
agent = Agent(
    'ollama:llama3-groq-tool-use:8b',   # 🦙 Local AI model via Ollama
    instructions="You are helpful assistant."
)

# ── MAIN FUNCTION ─────────────────────────────────────────────────────
def main():
    history = []  # 📋 Start with empty history — like a blank notebook

    # ── THE CHAT LOOP ──────────────────────────────────────────
    while True:
        user_message = input(">>")   # ⌨️ Wait for the user to type something
        if user_message == "q":
            break                    # 🚪 "q" = quit the chat loop

        result = agent.run_sync(user_message, message_history=history)
        # ☝️ Send message to AI, pass full history so AI remembers everything

        print(result.output)       # 🖨️ Print the AI's reply

        history.extend(result.new_messages())
                # ☝️ Add THIS round's messages to our running history list
                # .extend() = append multiple items at once (like += for lists)
                # After 3 chats: history has 6 messages (3 user + 3 AI replies)

    # ── SUMMARIZATION (after user quits) ──────────────────────
    summary_prompt = (
        "Please summarize the whole conversation until this message. "
        "Point out key topics and provide a timeline of events from this conversation."
    )
        # ☝️ We ask the AI to write a summary of EVERYTHING before saving
        # Why? So when we load later, the AI quickly "re-learns" the context!

    result = agent.run_sync(summary_prompt, message_history=history)
    print(result.output)          # Show the summary to the user

    # ── SERIALIZE & SAVE TO JSON ───────────────────────────────
    history_json = ModelMessagesTypeAdapter.dump_json(result.all_messages())
        # ☝️ THIS IS THE MAGIC LINE!
    # result.all_messages()     = ALL messages as Python objects
    # ModelMessagesTypeAdapter  = knows the exact structure of pydantic_ai messages
    # .dump_json()              = converts those Python objects → raw JSON bytes

    save_path = Path(__file__).parent.parent.resolve() / "data" / "history.json"
        # Path(__file__)          = path to THIS script file
    # .parent                 = go UP one folder (out of this script's directory)
    # .parent again           = go UP another folder
    # / "data" / "history.json" = go INTO data folder, target history.json

    with open(save_path, "wb") as f:
        f.write(history_json)
        # "wb" = Write Binary mode (because dump_json returns bytes, not text)
    # This physically writes the JSON to your hard drive! 💾

    print("history is saved")     # ✅ Confirmation message

if __name__ == "__main__":
    main()                         # 🚀 Only run if script is run directly (not imported)

# ── EXAMPLE CONVERSATION (comments at bottom) ─────────────────────
# Provide me with a good motto for today!
# Why did you choose this one?
# How about another one for my friend?
# (then type q to quit — summary is generated, then saved)
🔑 history.extend() vs history.append() — new_messages() returns a LIST of messages (user + AI). extend adds them all. append would add the whole list as one item — wrong!
💡 dump_json() returns bytes, not a string! That's why the file is opened in "wb" (write binary) mode, not "w" (write text) mode.
🔵 File 2 — json_deserialize.py (The LOADER)
📂 json_deserialize.py STEP 2 — LOAD & CONTINUE
🎯 What this file does: Loads the saved history.json file, converts the raw JSON back into proper AI message objects using ModelMessagesTypeAdapter.validate_python(), then asks the AI a NEW question — and the AI remembers everything from the previous session!
🌟 This is the payoff! The AI can now say "You asked about mottos before — here's a different one!" even though this is a brand-new Python process. True persistent memory! 
# ── IMPORTS ────────────────────────────────────────────────────────────
import json                            # 📄 Standard Python JSON library (for reading the file)
from pathlib import Path
from dotenv import load_dotenv
from pydantic_ai import Agent, ModelMessagesTypeAdapter
import logfire

load_dotenv(override=True)
logfire.configure()
logfire.instrument_pydantic_ai()

agent = Agent('ollama:llama3-groq-tool-use:8b', instructions="You are helpful assistant.")

# ── STEP 1: FIND THE SAVED FILE ────────────────────────────────────────
history_path = Path(__file__).parent.parent.resolve() / "data" / "history.json"
# Same path logic as serialize — go up 2 folders, then into data/history.json

# ── STEP 2: LOAD RAW JSON FROM FILE ────────────────────────────────────
with open(history_path, "rb") as f:
    history = json.load(f)         # Read bytes from file → Python dict/list
# At this point, history is just a plain Python list of dicts (raw JSON data)
# It looks like: [{"kind": "request", "messages": [...]}, ...]
# The AI can't use this yet — it needs PROPER pydantic_ai message objects!

# ── STEP 3: VALIDATE / DESERIALIZE ─────────────────────────────────────
history = ModelMessagesTypeAdapter.validate_python(history)
# ☝️ THIS IS THE MAGIC LINE!
# validate_python() takes the raw JSON dicts and converts them into
# proper typed pydantic_ai ModelMessage objects that the AI understands
# Without this step, passing raw JSON as message_history would CRASH! 💥

# ── STEP 4: CONTINUE THE CONVERSATION WITH MEMORY! ─────────────────────
result = agent.run_sync(
    "Tell me a different motto compared to past.",
    message_history=history       # ✅ Full history from previous session!
)
# The AI sees the saved conversation (motto discussion, etc.)
# And gives a DIFFERENT motto because it remembers what it said before!

print(result.output)   # 🎉 The AI's reply, contextually aware of past session!
print(result.usage())  # 📊 Token usage stats — how many tokens this call used
#                          (tokens = chunks of text; used for cost/rate-limit tracking)
⚠️ Why validate_python()? json.load() gives you plain Python dicts. pydantic_ai needs typed objects. Skipping validation = TypeError crash when you pass history to run_sync!
📊 result.usage() — returns token count stats (input tokens, output tokens). Think of tokens like "words" — helps you track API usage and cost!
⚔️ Serialize vs Deserialize — Side by Side
Feature 💚 json_serialize.py 🔵 json_deserialize.py
Purpose SAVE history to file LOAD history from file
Key method dump_json(all_messages()) validate_python(raw_data)
File mode "wb" — write binary "rb" — read binary
Input type Python ModelMessage objects Raw JSON bytes/dicts
Output type JSON bytes (written to file) Python ModelMessage objects
Extra feature Chat loop + Summarization result.usage() stats
Imports json? ❌ No (dump_json handles it) ✅ Yes (json.load needed)
🧠 The Smart Summarization Pattern
💡 This is a production-grade AI pattern used by real apps! Instead of saving ALL messages forever (which could be thousands), summarize and save a compact version.
  • 1
    User chats (3 messages about mottos)

    history grows to 6 messages. AI remembers everything within this session.

  • 2
    User types "q" to quit

    The while loop breaks. Now the summarization step kicks in automatically.

  • 3
    AI generates a summary

    "User asked for a motto → I gave 'Stay Curious'. User asked why → I explained. User asked for friend's motto → I gave 'Dream Big'."

  • 4
    Save ALL messages including summary to history.json

    The JSON file now contains the full conversation + the summary message at the end.

  • 5
    Next session: Load → validate → pass as history

    AI reads the summary and knows everything. "Tell me a DIFFERENT motto" → AI knows what mottos it gave before! ✅

📊 Bonus: What is result.usage()?
🪙

Tokens = Money

AI APIs charge by tokens (≈ ¾ of a word). result.usage() tells you how many tokens were used — input (your message + history) + output (AI's reply).

📈

Why It Matters

Stateful agents with long history use MORE input tokens each turn. That's why summarization matters — fewer tokens = faster + cheaper!

🛑

Context Limit

Every model has a max token limit (e.g. 8k, 32k, 128k). If your history is too long, the API throws an error! Summarization prevents this.

🎓 The Big Takeaway

These two files teach you how to give AI agents truly persistent memory — memory that survives beyond a single Python session!

The chain is: Chat → Summarize → dump_json() → .json file then later: json.load() → validate_python() → message_history=

Without ModelMessagesTypeAdapter, you'd either lose the history or crash — it's the translator between JSON and AI-land! 🌉
