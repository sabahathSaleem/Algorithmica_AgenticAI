🏫 Concepts First — What Are We Dealing With? START HERE
🤖

What is an AI Agent?

An AI agent is like a smart robot assistant you can talk to. You give it a job (instructions), ask it questions, and it replies! In code, it's the Agent object from pydantic_ai.

💬

What is a Message?

Every time you talk to an AI, your words = a message. The AI's reply = also a message. All these messages together form a conversation history — like a WhatsApp chat log!

🧠

Stateful vs Stateless

Stateless = AI has no memory. Every message is brand new. Stateful = AI remembers past messages. It's like talking to someone with amnesia vs someone with a good memory!

🪵

What is Logfire?

Logfire is a monitoring tool — like a CCTV camera for your AI agent. It records everything the agent does so you can debug problems later.

🔑

What is dotenv?

.env files store secret keys (like passwords). python-dotenv loads them so your code can use them without hardcoding secrets into your source files!

🦙

What is Ollama / LLaMA?

Ollama runs AI models locally on your computer. llama3-groq-tool-use:8b is a small but capable AI model with 8 billion parameters!

🧒

🍦 Think of it like an Ice Cream Shop!

Imagine you visit an ice cream shop. Stateless: Every visit, the staff has NO idea who you are — you have to tell them your name, allergies, everything from scratch each time. Stateful: The staff REMEMBERS you — "Oh, Thimmareddy! Your usual mango scoop, no nuts!" That memory = message_history in our code!

📨 File A — The Basics of Messages
📨 a_messages.py LEVEL 1 — BASICS
🎯 What this file does: This is the simplest file. It creates one AI agent, asks it one question ("tell me a joke"), and then shows you how messages are stored — both the NEW ones and ALL of them.
💡 Key idea: Every conversation produces TWO kinds of messages — new_messages() (just what happened THIS round) and all_messages() (the complete chat history). Understanding this is the foundation of memory! 
# ── IMPORTS ──────────────────────────────────────────────────
from dotenv import load_dotenv     # 🔑 Loads secret keys from a .env file
from pydantic_ai import Agent      # 🤖 The AI Agent "brain" builder
import logfire                       # 🪵 Logging/monitoring tool (like CCTV for AI)

# ── SETUP ────────────────────────────────────────────────────
load_dotenv(override=True)         # 📂 Read .env file; override any existing env vars
logfire.configure()               # 🛠️ Start logfire — turns on the CCTV
logfire.instrument_pydantic_ai()  # 🎯 Tell logfire to watch pydantic_ai specifically

# ── HELPER FUNCTION ──────────────────────────────────────────
def print_result(result):
    # 📢 Print just the final text answer from the AI
    print("\n\n### Output")
    print(f"\n {result.output}")    # result.output = the AI's answer text

    print("\n\n### New messages")
    messages = result.new_messages()  # 🆕 Only messages from THIS run
    for idx, message in enumerate(messages):
        print(f"\nMessage #{idx + 1}: {type(message).__name__}")
        # type(message).__name__  tells us if it's a UserPromptPart or ModelResponse
        print(message)

    print("\n\n### All messages")
    messages = result.all_messages()  # 📚 EVERY message ever (history + new)
    for idx, message in enumerate(messages):
        print(f"\nMessage #{idx + 1}: {type(message).__name__}")
        print(message)

# ── CREATE THE AGENT ──────────────────────────────────────────
agent = Agent(
    'ollama:llama3-groq-tool-use:8b',  # 🦙 Which AI model to use (local via Ollama)
    instructions="You are helpful assistant."  # 📋 The "personality" / role of the AI
)

# ── ASK ONE QUESTION ──────────────────────────────────────────
result = agent.run_sync("tell me a joke, in short")
# run_sync() = ask the AI and WAIT for the answer (synchronous = no async needed)
# No message_history here = AI starts fresh with zero memory

print_result(result)  # 🖨️ Show what happened
✅ new_messages() — Only the messages from the last run_sync() call. Like just tonight's WhatsApp messages.
📚 all_messages() — The COMPLETE conversation from beginning. Like your entire WhatsApp chat history.
🧠 File B — The Forgetting Agent (Stateless)
🧠 b_stateless_agents.py LEVEL 2 — STATELESS (NO MEMORY)
🎯 What this file does: It runs TWO separate conversations with the AI. First it introduces "Thimmareddy" to the AI. Then it asks "what is my name?" — but since there's NO memory passed between the calls, the AI has NO idea! 😂
🚨 Key gotcha: Each run_sync() call WITHOUT message_history = completely NEW conversation. The AI is like a goldfish — forgets everything after 3 seconds! 
# ... (same imports + setup + print_result + agent creation as file A) ...

# ── CONVERSATION TURN 1 ───────────────────────────────────────
result = agent.run_sync("i am thimmareddy and i am a researcher of AI and Consciousness")
# ☝️ No message_history argument = AI starts with EMPTY memory
# The AI hears this, replies nicely, and then... FORGETS everything
print_result(result)

# ── CONVERSATION TURN 2 ───────────────────────────────────────
result = agent.run_sync("what is my name?")
# ☝️ Again, no message_history!
# The AI has NO idea who you are. It will say something like:
# "I'm sorry, I don't know your name. You haven't told me yet."
# This is STATELESS behaviour — no memory between calls!
print_result(result)
🐟

🐟 The Goldfish Problem!

Each run_sync() without history = a completely new goldfish brain. You told the AI your name in round 1, but by round 2, that conversation is gone forever. The AI starts fresh with zero context. This is why chatbots forget you if you refresh the page!

💾 File C — The Remembering Agent (Stateful) ⭐ Most Important!
💾 c_stateful_agents.py LEVEL 3 — STATEFUL (WITH MEMORY) ⭐
🎯 What this file does: This is the MAGIC file! It runs 3 separate questions, but each time it passes the FULL history to the next call. So the AI actually remembers Thimmareddy's name and job across all 3 messages!
⭐ Key magic: message_history=result.all_messages() — this passes the ENTIRE chat log to the next question. The AI can now look back and say "Oh yes, you told me earlier that your name is Thimmareddy!" 
# ... (same imports + setup + print_result + agent creation) ...

# ── TURN 1: Introduce yourself ────────────────────────────────
result = agent.run_sync(
    "i am thimmareddy and i am a researcher of AI and Consciousness",
    message_history=[]  # 🆕 Start fresh — empty list = no history yet
)
print_result(result)
# After this, result.all_messages() contains:
# [UserMessage("i am thimmareddy..."), ModelResponse("Nice to meet you!")]

# ── TURN 2: Ask about name ────────────────────────────────────
result = agent.run_sync(
    "what is my name?",
    message_history=result.all_messages()
    # ☝️ THIS IS THE KEY! We pass ALL previous messages to the AI.
    # The AI now sees the full history and knows your name is Thimmareddy!
)
print_result(result)
# AI will reply: "Your name is Thimmareddy." ✅

# ── TURN 3: Ask about job ─────────────────────────────────────
result = agent.run_sync(
    "what do i do?",
    message_history=result.all_messages()
    # ☝️ This now contains ALL 3 turns of history (4 messages total!)
    # AI sees: intro → name question → name answer → job question
    # So it can correctly answer: "You are a researcher of AI and Consciousness!"
)
print_result(result)

⚔️ Stateless vs Stateful — Side by Side
Feature 🔴 Stateless (File B) 🟢 Stateful (File C)
Memory ❌ Forgets everything ✅ Remembers all history
message_history ❌ Not passed / missing ✅ result.all_messages()
Knows your name? ❌ "Who are you?" ✅ "You're Thimmareddy!"
Real-world analogy Goldfish 🐟 Best friend with a diary 📔
Use case One-shot tasks, classifiers Chatbots, assistants, agents
Context window grows? ❌ No (stays small) ⚠️ Yes (gets bigger each turn)
📈 How Memory Grows in Stateful Agents
  • 1
    After Turn 1

    all_messages() = [UserMessage("i am thimmareddy..."), ModelResponse("Nice to meet you, Thimmareddy!")] — 2 messages total

  • 2
    After Turn 2

    all_messages() = [previous 2 messages + UserMessage("what is my name?") + ModelResponse("Your name is Thimmareddy.")] — 4 messages total

  • 3
    After Turn 3

    all_messages() = [previous 4 messages + UserMessage("what do i do?") + ModelResponse("You are a researcher of AI and Consciousness.")] — 6 messages total

⚠️ Context Window Warning: As memory grows, you're sending MORE tokens to the AI each time. Very long conversations can get expensive or hit the AI's limit! Real apps use tricks like summarizing old messages to keep history short.
🔬 Key Functions Decoded
▶️

agent.run_sync()

Sends a message to the AI and waits for the reply. sync = synchronous = your code PAUSES until the AI is done. No async/await needed! Good for scripts.

🆕

result.new_messages()

Returns ONLY the messages from this specific run_sync() call. Like reading just today's new emails.

📚

result.all_messages()

Returns ALL messages — history that was passed in PLUS the new ones. This is what you pass as message_history to the next call to give the AI its memory!

💬

result.output

The simple text answer from the AI. While all_messages() gives you the full technical details, output just gives you the human-readable reply.

📋

instructions=

Sets the AI's "system prompt" — its personality and role. Like telling a new employee "You are a helpful customer service rep." It shapes ALL responses.

🔍

type(message).__name__

Python trick to get the class name of an object. So if a message is a UserPromptPart, this prints exactly that — useful for debugging!

🎓 The Big Takeaway

These 3 files show a progression: from "how do messages work?" → "what happens without memory?" → "how to give AI memory!"

The secret sauce is just one line: message_history=result.all_messages()

Pass the history → AI remembers. Forget the history → AI is a goldfish. 🐟
