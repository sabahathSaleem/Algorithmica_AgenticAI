Section 01

Core Concepts

Understand the building blocks before reading a single line of code.

🤖

What is pydantic_ai?

A Python framework that wraps LLM calls into a structured, type-safe Agent. Think of it as a universal remote control — one API to talk to any AI model, with validation baked in.

pip install pydantic-ai
🏭

LLM Provider

A service that hosts and runs an AI model. Could be local (Ollama on your machine) or cloud (OpenAI, Groq, Google). Each has its own API, keys, and pricing. pydantic_ai hides all those differences.

provider:model-name
🔑

API Key / Secrets

Every cloud provider needs proof that you are the one calling it — an API key. This key must never be hardcoded in code. It lives in a .env file and is loaded at runtime.

NEVER commit .env to Git!
⚡

run_sync vs await

LLMs are slow — they take time to reply. run_sync blocks your program and waits for the answer (simple, beginner-friendly). The async version lets you do other work while waiting — crucial for production agents.

agent.run_sync(...)
📊

Usage / Token Counting

Every LLM charges by tokens (roughly 3/4 of a word). response.usage() tells you how many prompt tokens (input) and completion tokens (output) were consumed — essential for cost control.

input + output tokens
📦

dotenv Pattern

A standard Python pattern: store secrets in a .env text file, load them into os.environ at startup using python-dotenv. Your code never sees the actual key value — it reads from the environment.

12-factor app pattern
💡 The Big Idea

All 6 files do the exact same thing — ask an LLM two questions. The only difference is the provider string passed to Agent(). This is the power of pydantic_ai's abstraction: swap one string, get a completely different model running in the cloud or locally.

Step-by-Step Execution Flow

1

Load Environment Variables

load_dotenv() reads your .env file and injects all key=value pairs into os.environ — the program's secret storage for the current session.

2

Instantiate the Agent

Agent('provider:model', instructions='...') creates a reusable agent object. The instructions becomes the system prompt — it tells the LLM its role before every message.

3

Run a Prompt Synchronously

agent.run_sync("your question") sends the question to the LLM provider over HTTPS. Your Python thread blocks (waits) until the full response is returned.

4

Read the Output

response.output contains the LLM's text answer as a Python string. response.usage() gives you a dict with token counts (prompt, completion, total).

5

Repeat as Needed

The same agent object is reused for a second call. Each run_sync() is an independent, stateless call — no memory of the previous message (unless you manage history explicitly).

Section 03

Environment Variables & dotenv

The secure, industry-standard way to handle API keys in any project.

📄 .env file (on disk)

OLLAMA_BASE_URL=http://localhost:11434
GROQ_API_KEY=gsk_xxxxxxxxxxxx
OPENAI_API_KEY=sk-xxxxxxxxxxxx
GITHUB_TOKEN=ghp_xxxxxxxxxxxx
OPENROUTER_API_KEY=sk-or-xxxxxxxxx
GOOGLE_API_KEY=AIzaxxxxxxxxxx
→

🐍 Python at runtime

from dotenv import load_dotenv, find_dotenv
import os

# find_dotenv() walks up dirs to find .env
load_dotenv(find_dotenv())

# Now you can read any key:
url = os.environ.get("OLLAMA_BASE_URL")

# pydantic_ai reads keys automatically
# based on the provider prefix you give it
⚠️ Critical Security Rule

Always add .env to your .gitignore file. Never commit real API keys to GitHub. If you accidentally push a key, revoke it immediately on the provider's dashboard — bots scan GitHub repos for leaked keys within seconds of a push.

🔍 find_dotenv() vs load_dotenv()

find_dotenv() (used in file 1/Ollama) walks up the directory tree to find .env — useful when running scripts from subfolders. Plain load_dotenv() with override=True (files 2–6) only looks in the current working directory but forces env vars to update even if already set. Both are valid patterns.

Runs LLMs 100% locally on your machine. No internet needed after download. Qwen3:4b is a 4-billion parameter model from Alibaba — tiny enough to run on a laptop GPU/CPU.

LOCAL FREE

CLOUD FREE TIER
GitHub Models 3_github.py
github:deepseek/DeepSeek-R1

Microsoft/GitHub hosts top models via Azure AI. Use your GitHub PAT token — great for students and developers already on GitHub. DeepSeek-R1 is a reasoning model from China.

CLOUD FREE (limited)
OpenRouter 4_open_router.py
openrouter:deepseek/deepseek-v3.2

A meta-router that gives you access to 300+ models from a single API key. It routes to cheapest/fastest provider automatically. Ideal for comparing models without multiple accounts.

ROUTER PAY-PER-USE
OpenAI 5_openai.py
openai:gpt-4o-mini

The original commercial LLM API, now the industry standard. GPT-4o-mini is fast and cheap — the go-to model for production apps that need reliable quality without breaking the bank.

CLOUD PAID
Gemini 6_gemini.py
google-gla:gemini-3-pro-preview

Google's flagship LLM. The google-gla prefix uses Google's AI Studio API (not Vertex AI). Gemini Pro excels at long context (1M tokens), multimodal tasks, and reasoning.

CLOUD FREE TIER

Commented Code

Every meaningful line explained. Read the comments as you would read the code.

1_ollama.py LOCAL MODEL 
# ─── IMPORTS ───────────────────────────────────────────────────────────────
from dotenv import load_dotenv, find_dotenv
# load_dotenv  → reads .env file and pushes variables into os.environ
# find_dotenv  → smart file-finder: walks UP parent dirs to locate .env
#               solves: "I'm in a subfolder and .env is at project root"

from pydantic_ai import Agent
# Agent is pydantic_ai's core abstraction — wraps any LLM in a unified interface
# It handles: auth, API calls, retries, type validation, history tracking

import os
# Standard Python module for reading environment variables


# ─── LOAD ENVIRONMENT VARIABLES ────────────────────────────────────────────
load_dotenv(find_dotenv())
# find_dotenv() → returns path to nearest .env file above current directory
# load_dotenv() → reads that file; now OLLAMA_BASE_URL is in os.environ
# Note: doesn't override existing env vars by default (safe for CI/CD)


# ─── GUARD CLAUSE: CHECK REQUIRED ENV VAR ──────────────────────────────────
if not os.environ.get("OLLAMA_BASE_URL"):
#  os.environ.get() returns None (not an error) if key is missing
#  "not None" is True → the if fires → we raise an error early
#  This is FAIL FAST design: crash loudly with a helpful message NOW
#  rather than silently fail 100 lines later with a cryptic error
    raise RuntimeError(
        "OLLAMA_BASE_URL is not set in the environment. "
        "Either add it to a .env file at the project root or set it manually, "
        "or instantiate the provider with OllamaProvider(base_url=...)"
    )
# Typically: OLLAMA_BASE_URL=http://localhost:11434
# This tells pydantic_ai WHERE your local Ollama server is running


# ─── CREATE THE AGENT ──────────────────────────────────────────────────────
agent = Agent(
    'ollama:qwen3:4b',
    # Format: 'provider:model-name'
    # 'ollama' → pydantic_ai knows to call localhost Ollama HTTP API
    # 'qwen3:4b' → model name (Alibaba Qwen3, 4 billion params)
    #              smaller = faster on CPU; bigger = smarter but slower

    instructions="You are a helpful assistant.",
    # This becomes the SYSTEM PROMPT — sent before EVERY message
    # It sets the LLM's "personality" and behavior context
    # You could write: "You are a Python expert who only answers in code"
)
# agent is REUSABLE — create once, call many times
# It holds the provider config and system prompt


# ─── FIRST CALL ────────────────────────────────────────────────────────────
response = agent.run_sync("Write a haiku about recursion in programming.")
# run_sync() = synchronous (blocking) execution
# The Python thread STOPS here and WAITS for the LLM to respond
# Internally it does: send HTTP POST → wait → receive → parse → return
# Returns a RunResult object (not a raw string!)

print(response.output)
# .output → the LLM's text response as a Python string
# Example output: "Function calls itself / Depth grows, base case waits still / Stack unwinds at last"

print(response.usage())
# .usage() → returns token consumption stats, e.g.:
# Usage(requests=1, request_tokens=28, response_tokens=34, total_tokens=62)
# request_tokens = your prompt (input) → you pay for this
# response_tokens = LLM's answer (output) → you pay more for this
# For local Ollama: no real cost, but good to track for performance


# ─── SECOND CALL (same agent, different question) ──────────────────────────
response = agent.run_sync("What is recursion in programming.")
# Note: agent remembers NO history — this is a FRESH, independent call
# The LLM doesn't know about the haiku question from above
# For multi-turn conversations, you'd use agent.run() with message_history=[]

print(response.output)
print(response.usage())

from pydantic_ai import Agent

load_dotenv(override=True)
# override=True  → if GROQ_API_KEY already exists in os.environ,
#                   REPLACE it with the value from .env
# This is useful during development when you want .env to always win
# Difference from file 1: no find_dotenv() — looks only in current dir
# pydantic_ai automatically reads GROQ_API_KEY from os.environ for 'groq:' models

    'groq:llama-3.3-70b-versatile',

    #   70B = much smarter than 4B, but cloud-hosted (Groq's LPU hardware)

)
